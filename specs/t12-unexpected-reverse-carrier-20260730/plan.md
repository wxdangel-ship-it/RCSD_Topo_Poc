# 实施计划

## 1. 影响面结论

本变更只需要修改 T12 业务实现和相关源事实。T12 已经接收 Segment、SWSD Road/Node、F-RCSD Road/Node、T05 锚点与 RCSDIntersection，所需事实完整；T10 仅编排阶段和登记产物，不解析问题枚举，因此无需修改其他模块。

## 2. 实现分层

1. 在 `models.py` 增加 `unexpected_reverse_carrier` 并提升 additive schema 版本。
2. 在 `candidate_audit.py`：
   - 保留既有 SWSD 要求方向检查；
   - 仅在要求方向全部满足后检查相反方向；
   - 用反向门户验证局部原始 F-RCSD 载体；
   - 用 SWSD 全图搜索反向替代路径并按既有几何阈值保守排除；
   - 输出候选、锚点、F-RCSD 路径和 SWSD 反向路径证据。
3. 在 `review_publish.py` 增加候选种类专属自动决策，不改变人工复核优先级。
4. 在 `outputs.py` 扩展字段与证据图层，保留旧字段。
5. 更新 T12 模块源事实与项目级 T12 描述，不改变任何入口。

## 3. 数据与几何策略

- 使用输入 Road 图层原始 CRS 构建证据，运算统一在米制 CRS；
- 使用当前 T12 已有的长度比、附加长度、走廊偏离和采样间距；
- 短 Segment 的两端 portal 按 SWSD 两端距离进行 Voronoi 分侧；双 T07 只允许同 canonical group、`portal_radius_m` 内的实际 raw endpoint 扩展，且不创建拓扑边；
- SWSD 反向替代路径按 canonical 语义图搜索，以降低误报；
- F-RCSD 正式反向证据必须在 raw 方向图成立；
- 不创建、不删除、不重排任何上游要素。

## 4. 风险与控制

- **误报风险：SWSD 另有反向绕行。** 搜索全图并以相同几何阈值自动排除。
- **误报风险：T03 锚点门户不稳定。** 仅双 T07 唯一标准面可自动确认。
- **候选 ID 冲突。** 只在要求方向已满足时检查反向，保持一个 Segment 一个候选。
- **性能风险。** 图只构建一次；每个单向 Segment 最多增加一次 F-RCSD 局部搜索和一次 SWSD 全图搜索，并记录耗时基线。
- **兼容风险。** additive schema；T10 不解析具体问题枚举。

## 5. 验证顺序

1. 先写失败测试；
2. 实现最小逻辑并跑 T12 单元测试；
3. 跑 T12 全模块测试和 T10 契约测试；
4. 用 1026960 真实输入跑两次，比较稳定哈希和三个冻结样例；
5. 验证 QGIS 图层、CRS、几何与审计清单；
6. 复核源码体量和仓库治理登记。
